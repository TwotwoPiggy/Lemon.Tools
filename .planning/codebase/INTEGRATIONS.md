# External Integrations

## AI & Machine Learning
- **Google.GenAI**: Gemini integration for content generation.
- **Azure.AI.Projects / Microsoft.Agents.AI.Foundry**: For integrating with Microsoft's AI and foundry logic.
- **Mscc.GenerativeAI.Microsoft**: Supplemental AI models.

## Identity & Network
- **Azure.Identity**: For authentication.
- **Polly**: For HTTP resilience and retry logic.
- custom `HttpManager` mapping to standard `WebRequest` and `HttpClient` proxies.

## System & Local
- **SQLite**: Local relational database via `SQLite.Core`.
- **Tesseract**: Local optical character recognition via `OcrApi`.
- **Win32**: Deep OS integration via `Win32Api` and UI automation.
